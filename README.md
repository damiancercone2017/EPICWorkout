# Gym Workout Tracker

A mobile-first workout tracking web app built with a single HTML file. Let's you log and follow daily workouts provided by FFC AI Consulting.

## Features

- **Daily workout navigation** - Browse through each day of the week with gym, run, cardio, and rest day badges
- **Exercise tracking** - Log sets, reps, and weights for each exercise
- **Tab-based layout** - Organised view for easy navigation between workout sections
- **Progress indicators** - Visual progress dots to track completed workouts
- **Mobile optimised** - Built for iOS and Android with a responsive, app-like interface
- **Offline ready** - Runs entirely in the browser with no internet connection required after loading

## Getting Started

1. Download or clone this repository
2. Open `workout-tracker.html` in any modern web browser
3. No installation or dependencies required
